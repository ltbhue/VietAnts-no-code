| Thư mục | Nguồn | Số ảnh |
|---------|--------|--------|
| `14-bieu-do-trinh-tu-gop-nhom/` | `14-bieu-do-trinh-tu-gop-nhom.md` | 12 (trình tự) |

**Tổng: 72 file PNG** (48 + 24 cho file 17). Mỗi thư mục có `manifest.json` liệt kê tên file.

Ảnh file **17**: `stt-01-sequence.png`, `stt-01-activity.png`, … `stt-12-activity.png` — nhúng trực tiếp trong `17-dac-ta-chuc-nang-gop-nhom.md`.

Quy tắc đặt tên: `stt-XX-{sequence|activity}-{ten-nhom}.png`

Chèn vào Word: **Chèn → Hình ảnh** từ thư mục tương ứng (ví dụ Hình 3.5.2a = `stt-02-sequence-...`).
